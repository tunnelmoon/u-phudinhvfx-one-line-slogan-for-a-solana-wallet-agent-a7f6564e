# One-Line Slogan for a Solana Wallet Agent

A make.fun bounty entry. `main.ts` writes a single slogan for a Solana wallet agent to `entry.txt`.

> Solana speed, human sense: a wallet agent that does the doing for you.

Run with `MAKEFUN_OUTPUT_DIR` set to choose where `entry.txt` is written (defaults to `/output`).
